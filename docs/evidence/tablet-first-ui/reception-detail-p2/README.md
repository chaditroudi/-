# Reception detail — before / after (7 Nov 2026)

Generated by `QC_VISUAL_MODE=detail node scripts/e2e/qc-inspection-visual.e2e.mjs` on a private stack (loopback replica set,
API :4186, Vite :8186, `APP_ENV=test`), one locale per run (`QC_VISUAL_LOCALES=fr` / `ar`) to keep memory low. Each walk books a
real delivery, signs in as `chef.reception@test.local`, opens it from today's reception list, checks that Corriger and
Annuler la réception are offered before the QC decision, opens both dialogs and closes them without writing, captures every
section (Fiche, Lots, Qualité, Entrepôt, Documents, Historique) and opens a lot's weighing record from "Voir la pesée".

- `before/`: the screen at `09b2121` (previous design), fr and ar × 375, 768, 1024, 1440; 161/169 checks. The 8 failures were
  a defect of the harness probe for "Voir la pesée" (the next check clicked that same button and passed); fixed since.
- `after-fr/`, `after-ar/`: the redesigned screen, 375, 768, 1024, 1440 each; **109/109 checks per locale**, including the
  correction and cancellation dialogs. Arabic shows the next step, statuses, page title, search, live status, weighing source
  and both dialogs in Arabic.
- Controls under 44 px at touch widths: only the shell header's search button, the same before and after (not this screen).
- Not done in this pass: submitting a correction or a cancellation (the reception suite's correction scenario covers the
  submission), lot release/quarantine (needs a QC decision first), GS1 label printing.
